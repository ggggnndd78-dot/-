# Ghiyarak

الجزئية الأولى من تطبيق غيارك بصيغة مؤسسة وبدون Bootstrap.

## المحتوى الحالي
- Foundation architecture لتطبيق Flutter
- Theme واضح وهوية أولية للتطبيق
- Router منظم
- Storage جاهز
- Network layer جاهزة
- Splash + Entry + Login + OTP
- Profile basics + Location selection + Vehicles
- استخدام الشعار الأصلي داخل التطبيق

## التشغيل
```bash
flutter clean
flutter pub get
flutter run
```

## ملاحظة
هذه الجزئية الأولى فقط. الربط الحقيقي مع Backend وMySQL وPrisma سيكون في الجزئية التالية.
