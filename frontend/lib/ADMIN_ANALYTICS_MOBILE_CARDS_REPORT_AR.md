# تقرير ضبط تقارير وتحليلات الإدارة للجوال

تم ضبط صفحة التقارير والتحليلات الإدارية لتكون مناسبة لشاشات الجوال بدل التصميم الكبير السابق.

## الملفات المعدلة

- `lib/features/admin/presentation/pages/admin_analytics_page.dart`

## أهم التعديلات

- تحويل المؤشرات إلى بطاقات صغيرة مناسبة للجوال.
- جعل أقسام التقارير شريطًا أفقيًا قابلًا للتمرير.
- استبدال جدول السجلات الكبير ببطاقات صغيرة مختصرة على الجوال.
- تصغير الهيدر وأزرار التحديث والتصدير حتى لا تزاحم الشاشة.
- جعل الرسم الشريطي عموديًا ومناسبًا للعرض الضيق.
- الإبقاء على نفس مصادر API الحقيقية للتقارير والتحليلات.
- الحفاظ على الثيم الداكن والاتجاه RTL/LTR حسب إعدادات التطبيق.

## ملاحظة

لم يتم تغيير الراوتر أو الباكند أو أسماء API. التعديل محصور في واجهة التحليلات داخل مجلد `lib`.
