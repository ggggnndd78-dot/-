# تقرير مرحلة التقارير والتحليلات الإدارية

تم تطبيق مرحلة التقارير والتحليلات داخل لوحة الإدارة في مجلد `lib` فقط.

## الملفات المعدلة

- `features/admin/presentation/pages/admin_analytics_page.dart`
- `features/admin/data/admin_repository.dart`
- `core/i18n/app_localizations.dart`

## ما تم ضبطه

- إعادة بناء صفحة التقارير والتحليلات بشكل احترافي ومتجاوب.
- إضافة لوحة مؤشرات KPI للإدارة.
- عرض مصادر التحليل المتاحة:
  - ملخص لوحة الإدارة.
  - تحليلات المنصة.
  - الطلبات.
  - الإيرادات.
  - الدعم.
  - التجار.
  - لقطات التحليلات.
- إضافة أقسام تنقل داخلية للتقارير بدون تغيير الراوتر.
- إضافة رسوم شريطية خفيفة بدون الاعتماد على مكتبات خارجية.
- إضافة جداول معاينة لأحدث السجلات.
- إضافة زر تحديث البيانات.
- إضافة زر تحديث لقطات التحليل.
- إضافة تصدير CSV إلى الحافظة.
- جعل الصفحة تتحمل فشل بعض مصادر البيانات بدون أن تنهار كلها.
- إضافة ترجمات عربية وإنجليزية للنصوص الجديدة.
- الحفاظ على مسار الإدارة الحالي `/admin/analytics`.
- الحفاظ على الصلاحيات والقائمة الحالية وعدم كسر عمليات التاجر أو العميل.

## ملاحظات

لم يتم تعديل الباكند في هذه المرحلة لأن المطلوب كان مجلد `lib` فقط. الواجهة تستخدم endpoints الموجودة مسبقًا في `ApiEndpoints` وتعرض fallback آمن إذا لم يرجع أحد المصادر بيانات.
