# 06 Platform Access Rules

## Guest

Can browse public content only.

## Customer

Can login, manage profile, browse, and later buy/book after marketplace phases.

## Provider owner

Merchant/Workshop/Warehouse owner can start onboarding and can only access operational dashboard after approval.

## Employee

Can access only organization and branch scopes granted by owner/admin.

## Admin

Can review accounts, verification requests, users, audit logs, and platform settings.
