# 01 — المتطلبات النهائية لمنصة Ghiyarak Enterprise v2.0

## 1. تعريف النظام

Ghiyarak منصة يمنية متكاملة لبيع قطع غيار السيارات وحجز خدمات السيارات، تدعم تعدد البائعين، الورش، المستودعات، العملاء، التوصيل، الدفع الحقيقي، الإدارة، الدعم، المالية، والإشعارات.

النظام ليس متجرًا بسيطًا، بل منصة أعمال متعددة الأدوار Multi-Role Platform قابلة للتوسع والإنتاج.

## 2. الدولة والعملة

- الدولة المستهدفة: الجمهورية اليمنية.
- العملة الأساسية: الريال اليمني YER.
- اللغة الأساسية: العربية.
- اللغة الثانية: الإنجليزية.
- اتجاه الواجهة الأساسي: RTL.

## 3. المنصات

النظام يعمل من خلال:

- تطبيق Android.
- Flutter Web.
- Windows Desktop.

كل منصة يمكن أن يستخدمها أكثر من دور، لكن الواجهة التي تظهر للمستخدم تعتمد على:

- الدور Role.
- الصلاحيات Permissions.
- حالة الحساب.
- حالة اعتماد المؤسسة.
- الفرع المسموح له.
- نوع المؤسسة: تاجر، ورشة، مستودع.

## 4. الأدوار الأساسية

## 5. القاعدة الجوهرية للحسابات

يوجد فرق بين:

### User Account

الحساب الشخصي للمستخدم: رقم جوال، إيميل، اسم، جلسات، OTP، أدوار.

### Organization Account

النشاط التجاري المرتبط بالمستخدم: متجر، ورشة، مستودع، فروع، وثائق، حسابات بنكية، موظفين، صلاحيات داخلية.

## 6. منطق التسجيل

### العميل

- ينشئ حسابًا.
- يتحقق عبر OTP.
- يصبح Active مباشرة.
- لا يحتاج موافقة إدارية.
- يستطيع استخدام واجهات العميل مباشرة.

### التاجر

- ينشئ حساب مستخدم.
- يتحقق OTP.
- ينشئ ملف نشاط تجاري.
- يضيف بيانات المتجر والفرع والحساب البنكي والوثائق.
- يرسل طلب اعتماد.
- لا يستطيع إدارة المنتجات أو الطلبات قبل الموافقة.

### الورشة

- تنشئ حساب مستخدم.
- تتحقق OTP.
- تنشئ ملف ورشة.
- تضيف الخدمات والفروع والوثائق والحساب البنكي.
- ترسل طلب اعتماد.
- لا تستطيع استقبال الحجوزات قبل الاعتماد.

### المستودع

- ينشئ حساب مستخدم.
- يتحقق OTP.
- يضيف بيانات المستودع والفروع والوثائق.
- ينتظر اعتماد الإدارة.

### الموظف

- لا ينشئ مؤسسة مستقلة.
- يتم إنشاؤه أو دعوته من مدير المتجر أو الورشة أو المستودع.
- يحصل على صلاحيات محددة حسب الفرع والدور الداخلي.

## 7. المتطلبات الأساسية

- JWT Access/Refresh.
- OTP عبر الإيميل والجوال.
- Guest Sessions.
- RBAC.
- صلاحيات موظفين حسب الفرع.
- تدقيق Audit Logs.
- إشعارات Email + In-App، مع قابلية إضافة Push لاحقًا.
- موافقات إدارية للتجار والورش والمستودعات.
- استيراد منتجات من Excel للتجار والورش والمستودعات المعتمدين.
- دفع حقيقي قابل للربط مع البنوك والمحافظ.
- قيود محاسبية متوازنة.
- حماية البيانات الحساسة.
- واجهات لكل دور حسب سياساته.
